## 一、角色扮演 AI 研究现状

### 1.1 复旦三层人格分类框架（2024）

论文：*From Persona to Personalization*

将角色扮演AI分为三层：

| 层级 | 说明 | 例子 |
|------|------|------|
| 群体人格 | 共同特征的人群（职业、性格类型） | "你是一个程序员" |
| 角色人格 | 广为人知的具体个体 | "你是孙悟空" |
| 个性化人格 | 基于个人数据构建的独特身份 | **我们在做的48** |

第三层最难——需要持续更新的数字档案、独特的经历和偏好、跨会话的一致性。

参考：https://finance.sina.com.cn/roll/2024-12-27/doc-ineawpit0480566.shtml

### 1.2 Character-LLM（可训练角色扮演 Agent）

核心思路：用角色的个人资料 + 经验 + 情绪状态来训练 Agent。

与我们 Phase 5 微调方案高度一致：
- 他们用经验上传框架
- 我们用历史对话 + 合成数据 + LoRA 微调

在人格、价值观、记忆、幻觉和稳定性方面接近 ChatGPT 水平。

参考：https://www.15zhi.net/blog/202411-论文研读-character-llm-a-trainable-agent-for-role-playing/

### 1.3 人格一致性评估基准

**CharacterEval**：1785 个多轮对话，77 个中文角色，评估维度包括：
- 知识一致性 / 人格一致性
- 流畅性 / 连贯性
- 人类相似度 / 共情能力

**RPEval**：四维度——情绪理解、决策制定、道德对齐、角色内一致性

未来我们评估48的效果可以参考这些维度。

参考：https://zhuanlan.zhihu.com/p/1921215652938614303

## 二、记忆系统研究

### 2.1 主流架构：短期 + 长期记忆

和我们 Phase 2 设计完全一致：

```
短期记忆：当前会话上下文（内存缓存）
长期记忆：历史对话向量化 → 向量数据库（Qdrant）→ 相似度检索 → 注入上下文
```

研究共识：
- 短期记忆用动态缓存
- 长期记忆由事件摘要器提炼为摘要，编码为向量存入长期记忆库
- 检索时做时间加权 + 相似度排序

参考：https://blog.csdn.net/2401_85325726/article/details/151706941

### 2.2 新方向：KV Cache 记忆架构（MemArt，2025）

传统方案的问题：
- 对话摘要会丢失语义依赖
- 打断前缀缓存（prefix cache），影响推理效率

MemArt 提出以 KV Cache 为中心的记忆架构，直接缓存注意力状态而非文本摘要。

**对我们的启示**：Phase 2 先用传统向量检索方案跑通，Phase 5 自己的模型可以考虑 KV Cache 方案优化。

### 2.3 私有工作记忆

最新研究证明：仅依赖公开对话历史的 Agent 不可能同时满足一致性与保密性。

需要显式引入"私有工作记忆"——48 有些想法不需要说出来，但要记住。

**对我们的启示**：Phase 4 情感系统可以作为私有记忆的载体。

## 三、让 LLM 像真人聊天

### 3.1 核心问题

LLM 在以下方面容易露馅：
- 对话开头/结尾不自然
- 过度附和（exaggerated alignment）
- 轮流说话节奏不对
- 回复过长、过于正式

### 3.2 实战参考：聊天记录微调

Edward Donner 用 24 万条真实短信微调 LLM：
- 至少需要 **1000+ 条消息**才能学到一个人的风格
- 关键因素：prompt 设计、输入数据格式、生成方式
- 能够以令人信服的方式模仿作者和朋友

参考：https://edwarddonner.com/2024/01/02/fine-tuning-an-llm-on-240k-text-messages/

### 3.3 DPO 微调（Direct Preference Optimization）

用 Llama 3 70B/405B 做实验，通过 DPO 让模型：
- 偏好口语化回复而非正式回复
- 平衡随意的对话语言与结构化对话

**对 Phase 5 的启示**：LoRA SFT 学"说什么"，DPO 调"怎么说"。两者结合效果最好。

参考：https://arxiv.org/html/2501.05032v1

## 四、对项目各阶段的指导

### Phase 1（已完成）
- ✅ 基础对话框架
- ✅ 人格提示词注入
- 改进方向：持续调优 prompt 让聊天更自然

### Phase 2（记忆系统）
- 架构设计与主流研究一致，方向正确
- 关键：重要性评分 + 时间衰减 + 相似度检索三者结合
- 注意摘要不要丢太多语义

### Phase 3（关系系统）
- 参考 CharacterEval 的评估维度设计信任度系统
- 引入私有记忆概念：48 对每个人的内心评价不一定说出来

### Phase 4（情感系统）
- 情绪状态作为私有工作记忆的载体
- 参考研究中的"适应性情感响应"设计情绪衰减机制

### Phase 5（微调）
- 数据量目标：至少 1000+ 条真实对话（Phase 1-4 积累）
- 训练方案：LoRA SFT + DPO 两阶段
  - 第一阶段 SFT：学习48的知识和行为模式
  - 第二阶段 DPO：调整说话风格和语气偏好
- 反例数据很重要：教模型什么不该说
